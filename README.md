# 📊 AmazingMart EU2 Sales Performance Dashboard

This Power BI project presents a comprehensive sales performance analysis for Amazing Mart in the EU2 region. It is designed to deliver executive-ready insights across multiple business dimensions including product performance, customer behavior, geographic trends, and operational efficiency.

## 🚀 Project Overview

The dashboard is segmented into multiple interactive pages, each tailored to answer specific business questions and support decision-making:

- **Index**: Navigation hub for all dashboard sections.
- **Executive Summary**: High-level overview of sales, profit, and regional performance.
- **Product Performance**: Deep dive into product-level metrics across categories and sub-categories.
- **Customer Insights**: Behavioral and segment analysis (not shown in screenshots).
- **Geographic Performance**: Country and regional breakdowns (partially shown).
- **Churn Analysis**: Customer retention and loss metrics (not shown).
- **Shipping & Delivery**: Operational KPIs and logistics performance (not shown).
